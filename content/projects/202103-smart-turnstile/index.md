## Overview

This project developed an intelligent turnstile system for both left-handed and right-handed users. The system used an Arduino and a Time-of-Flight sensor to detect gesture-based distance patterns and trigger the appropriate opening motion.

## Motivation

Conventional access-control interfaces can be inconvenient when they assume a single preferred hand or interaction direction. This project explored a sensor-based turnstile interaction that responds to both left- and right-hand gestures.

## System

- Integrated an Arduino controller with a Time-of-Flight distance sensor.
- Designed gesture logic based on distance-pattern changes.
- Implemented responses for both left-hand and right-hand opening motions.
