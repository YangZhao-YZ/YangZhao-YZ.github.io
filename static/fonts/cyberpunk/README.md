# Cyberpunk theme fonts

Self-hosted alternatives to the commercial fonts used by cyberpunk.net.

- Teko variable, weights 300–700: https://github.com/google/fonts/tree/main/ofl/teko
- Rajdhani Medium (500) and Bold (700): https://github.com/google/fonts/tree/main/ofl/rajdhani

Downloaded from the Google Fonts repository on 2026-09-17 and converted from TTF
to WOFF with fontTools without removing glyphs or changing font names. Both use
the SIL Open Font License 1.1; the corresponding license files are included.

Teko is used for headings. Rajdhani is used for body text and interface labels.
No request to a third-party font service is made at runtime.
